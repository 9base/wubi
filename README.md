# Wubi — preserved historical Ubuntu installer source

This repository preserves historical **Windows Ubuntu Installer (Wubi)**
source. GitHub does not label it a fork, but the installer is third-party Ubuntu
work, not a 9base implementation. [AUTHORS](AUTHORS) credits **Agostino Russo**
as author/maintainer; inherited history includes Ubuntu maintainers and
Bazaar-era artifacts. The [Debian changelog](debian/changelog) records Wubi 14.10
in 2014, and the latest inspected source commit is Colin Watson's October 2014
build-dependency adjustment.

The hosting object's December 2020 creation and April 2021 push timestamps do
not establish original software-development dates or a transfer into 9base.
The exact import mechanism, original import remote and full baseline delta
remain unresolved. The archive's purpose is historical source reference; it
does not claim ongoing 9base installer work.

The original [README](README), [AUTHORS](AUTHORS), [THANKS](THANKS), [LICENSE](LICENSE)
and source remain unchanged. The README describes the historical architecture,
file-backed Ubuntu installation and Wine/Windows build process. Its old website
and guide links are provenance pointers, not a claim of current support, safe
installation on modern systems or newly verified buildability.
